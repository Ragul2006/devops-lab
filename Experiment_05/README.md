# Experiment 5: JUnit test for add() method

## Aim
Write and execute a JUnit 5 test for a Calculator add() method.

## Procedure
1. Ensure Java and Maven are installed.
2. Open a terminal in this experiment folder.
3. Run:
```cmd
mvn clean test
```

## Expected output
```text
Tests run: 1, Failures: 0, Errors: 0
BUILD SUCCESS
```
